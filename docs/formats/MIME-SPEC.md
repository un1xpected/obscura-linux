# Obscura MIME Types

## Proposed MIME Types
- application/vnd.obscura.cfg
- application/vnd.obscura.theme
- application/vnd.obscura.lab
- application/vnd.obscura.pack
- application/vnd.obscura.profile

## File Extensions
- .obcfg
- .obtheme
- .oblab
- .obpack
- .obprofile

## Desktop Association
Each MIME type should have:
- icon
- default application
- file chooser display name
- tooltip / description

## Default Handler Strategy
- .obcfg → Obscura Config Center
- .obtheme → Obscura Theme Manager
- .oblab → Obscura Lab Runner
- .obpack → Obscura Pack Manager
- .obprofile → Obscura Profile Manager

# Obscura MIME Registry

## MIME Types

- application/vnd.obscura.cfg
- application/vnd.obscura.theme
- application/vnd.obscura.lab
- application/vnd.obscura.pack
- application/vnd.obscura.profile

## Extensions

- .obcfg
- .obtheme
- .oblab
- .obpack
- .obprofile

## Default Application Mapping

- .obcfg     -> Obscura Config Center
- .obtheme   -> Obscura Theme Manager
- .oblab     -> Obscura Lab Runner
- .obpack    -> Obscura Pack Manager
- .obprofile -> Obscura Profile Manager

## Icon Mapping

- obcfg     -> obscura-cfg
- obtheme   -> obscura-theme
- oblab     -> obscura-lab
- obpack    -> obscura-pack
- obprofile -> obscura-profile

## Rules

- no auto-execution
- no privilege escalation
- explicit user action required
- signature verification for release bundles

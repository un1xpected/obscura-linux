# Obscura Desktop Association Plan

## Goal
Register Obscura custom formats so file managers and launchers can recognize them.

## Association Targets

### .obcfg
- Display name: Obscura Configuration Bundle
- Default app: Obscura Config Center
- MIME: application/vnd.obscura.cfg

### .obtheme
- Display name: Obscura Theme Bundle
- Default app: Obscura Theme Manager
- MIME: application/vnd.obscura.theme

### .oblab
- Display name: Obscura Lab Bundle
- Default app: Obscura Lab Runner
- MIME: application/vnd.obscura.lab

### .obpack
- Display name: Obscura Package Bundle
- Default app: Obscura Pack Manager
- MIME: application/vnd.obscura.pack

### .obprofile
- Display name: Obscura Profile Bundle
- Default app: Obscura Profile Manager
- MIME: application/vnd.obscura.profile

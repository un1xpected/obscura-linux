# Obscura MIME Registry Plan

## Register These Types
- application/vnd.obscura.cfg
- application/vnd.obscura.theme
- application/vnd.obscura.lab
- application/vnd.obscura.pack
- application/vnd.obscura.profile

## Per-file metadata
- filename extension
- human-readable description
- default icon
- default application
- bundle signature requirement

## Integration targets
- desktop file association
- file manager preview
- installer profile import
- theme manager import
- lab runner import

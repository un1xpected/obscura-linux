# Obscura Desktop Composition Spec

## Desktop Mood
- dark
- calm
- precise
- premium
- controlled

## Surface Hierarchy
1. Background
2. Surface cards
3. Borders
4. Accent highlights
5. Text

## Panel
- thin
- semi-transparent
- 1px border
- no oversized widgets
- clean spacing

## Launcher
- centered
- rounded
- compact
- keyboard-first
- accent line only

## Notifications
- small cards
- dark background
- minimal icons
- short titles
- no noisy animation

## Lock Screen
- logo centered or slightly above center
- time prominent
- blur background
- simple password field

## Login Screen
- Obscura sigil
- subtle vignette
- strong readability
- almost no clutter

## Wallpaper Strategy
- hero wallpaper for first impression
- login wallpaper for clarity
- minimal wallpaper for icon-heavy use
- dark wallpaper for night mode

## Motion Language
- fade
- ease
- subtle slide
- no bounce
- no loud glow

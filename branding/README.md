# Obscura Visual Identity

This folder defines the official visual language of Obscura Linux.

## Locked decisions
- Palette: Obscura Noire
- Primary accent: violet
- Secondary accent: cyan
- Typography: Inter + JetBrains Mono
- Cursor: Bibata Modern Ice
- Icons: Papirus-Dark baseline, custom later
- Logo concept: Obscura Sigil

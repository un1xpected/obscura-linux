# Obscura MIME Icons

This directory contains the source icons for Obscura custom file formats.

## Design language
- dark
- geometric
- circular seal / sigil based
- violet + cyan accents
- minimal internal symbol changes per file type

## Planned icon names
- obscura-cfg
- obscura-theme
- obscura-lab
- obscura-pack
- obscura-profile

## Usage
These icons will be used in:
- file manager previews
- MIME association
- installer import dialogs
- theme manager
- profile manager
- pack manager

# Obscura Linux — Brand Book

## Brand Essence
Obscura Linux is a quiet, controlled, premium Linux distribution focused on cybersecurity, gaming, and lightweight daily use.

## Brand Personality
- disciplined
- precise
- nocturnal
- technical
- premium
- minimal
- confident

## Visual Direction
Obscura Noire uses:
- deep black foundations
- violet as the primary brand accent
- cyan as the interaction accent
- minimal motion
- clean typography
- geometric symbol language

## Logo Direction
The logo should feel like:
- a sigil
- a sealed core
- a ring with a hidden center
- a subtle eye/rune/halo hybrid

The logo must NOT feel like:
- a skull
- a generic hacker mask
- a neon cyber meme
- a gaming clan badge

## UI Rules
- dark surfaces first
- accent colors used sparingly
- 1px borders
- rounded corners
- readable typography
- subtle blur only where needed

## Tone of the System
Obscura should feel:
"silent, precise, and ready"

## Do Not
- overuse neon
- use random RGB gradients
- use futuristic fonts everywhere
- use noisy wallpapers
- use aggressive glitch as the default language

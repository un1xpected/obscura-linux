# Obscura Logo Concept

## Name
Obscura Sigil

## Shape Language
- circular ring
- hidden center
- thin cut or aperture
- slight halo impression
- geometric symmetry

## Meaning
The mark should communicate:
- secrecy
- focus
- protection
- precision
- system control

## Style
- geometric
- minimal
- premium
- not aggressive
- not comic
- not literal

## Usage
- boot screen
- login screen
- wallpaper
- installer splash
- docs cover
- favicon
- app/about panels

## Versions Needed
- full color
- monochrome light
- monochrome dark
- reversed
- icon-only

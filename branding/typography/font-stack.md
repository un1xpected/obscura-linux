# Obscura Typography System

## Primary UI Font
- Inter

## Secondary / Display Font
- Inter SemiBold or Inter Medium

## Monospace
- JetBrains Mono

## Fallback Fonts
- Noto Sans
- DejaVu Sans
- Noto Sans Symbols

## Cursor Theme Direction
- Bibata Modern Ice

## Icon Theme Direction
- Papirus-Dark baseline first
- custom Obscura icon pack later

## Typography Rules
- readable before stylish
- no overly futuristic fonts
- no condensed UI fonts
- no decorative login fonts
- monospace reserved for terminal / code / small technical labels
